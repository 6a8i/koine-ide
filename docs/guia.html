Instalar

Baixe o arquivo do seu sistema na página de Releases (o botão Baixar no topo já escolhe o certo). Todos são gerados automaticamente pelo GitHub Actions a partir do código-fonte; nenhum pede senha de administrador.

Windows 10/11 (64 bits)

  1. Baixe Koine.IDE_x.y.z_x64-setup.exe. Há também um .msi para instalação em rede.
  2. Execute o arquivo. O instalador coloca o programa só na sua conta de usuário.
  3. Como o instalador ainda não é assinado digitalmente, o SmartScreen pode mostrar "O Windows protegeu o computador". Clique em Mais informações e depois em Executar assim mesmo. Se o navegador bloquear o download, escolha Manter.
  4. Pronto: o Koiné IDE aparece no menu Iniciar e arquivos .koi passam a abrir com duplo clique.

Linux (x86-64)

  1. AppImage (qualquer distribuição): baixe Koine.IDE_x.y.z_amd64.AppImage, dê permissão de execução e abra: 
    chmod +x Koine.IDE_*.AppImage
./Koine.IDE_*.AppImage
    Para aparecer no menu de aplicativos, use um integrador como o AppImageLauncher ou o Gear Lever.
  2. Debian, Ubuntu, Mint e derivados: baixe Koine.IDE_x.y.z_amd64.deb e instale com sudo apt install ./Koine.IDE_x.y.z_amd64.deb (ou duplo clique). O pacote registra o Koiné IDE no menu e associa os arquivos .koi.
  3. Pré-requisito: WebKitGTK 4.1, já presente em distribuições de 2022 em diante (Ubuntu 22.04+, Debian 12+, Fedora 36+). Em Fedora, openSUSE e Arch use o AppImage.

macOS 11 ou mais recente

  1. Baixe Koine.IDE_x.y.z_universal.dmg (um só arquivo para Intel e Apple Silicon), abra e arraste o Koiné IDE para Aplicativos.
  2. Na primeira abertura o macOS avisa que o aplicativo é de um desenvolvedor não identificado, porque ele não é assinado nem notarizado pela Apple. Clique com o botão direito no aplicativo → Abrir → Abrir. Isso só é preciso uma vez.
  3. Se o sistema disser que o aplicativo "está danificado", é a quarentena do download: no Terminal, execute xattr -d com.apple.quarantine "/Applications/Koiné IDE.app" e abra de novo.
Para atualizar, basta instalar a versão nova por cima. Seus arquivos ficam onde você salvou; o rascunho não salvo e as preferências ficam na IDE.

A janela

  • Barra de ferramentas: Novo, Abrir, Salvar (e, no modo projeto, Pasta e Salvar tudo); Executar, Depurar, Testar e Parar; Exemplos, Referência, o seletor de idioma e o tema claro/escuro.
  • Abas: cada arquivo aberto é uma aba. O ponto indica alterações não salvas. Clique do meio ou Ctrl+W fecha; Ctrl+Tab alterna.
  • Editor: destaque de sintaxe, autocompletar (comece a digitar ou Ctrl+Espaço), dobra de blocos na margem, busca com Ctrl+F, múltiplos cursores com Alt+clique. Passe o mouse sobre uma palavra reservada para ver uma explicação; sobre uma variável, depois de executar, para ver o valor.
  • Console: saída do programa, entrada de dados e mensagens. Arraste a borda para mudar a altura. Os botões à direita mostram o painel de Variáveis ou de Testes.
  • Painel do projeto (à esquerda, quando uma pasta está aberta): árvore de arquivos com menu de contexto. Ctrl+B mostra ou esconde.

Escrever e executar

Um programa novo (Ctrl+N) já vem com o esqueleto mínimo: o bloco programa e a função inicio(), por onde a execução começa.

programa
{
    funcao inicio()
    {
        escreva("Olá, mundo!\n")
    }
}

Pressione F5 (ou Ctrl+Enter, ou o botão Executar). A saída aparece no console junto com o tempo de execução. Parar (Shift+F5) interrompe um programa que não termina. O programa roda em segundo plano, então a janela nunca trava, mesmo num laço infinito.

Salve com Ctrl+S. Enquanto não salvar, o texto fica guardado como rascunho e volta quando você reabre a IDE.

Ler dados

Quando o programa chega a um leia(...), o console abre uma linha de entrada. Digite o valor e pressione Enter. Vários valores no mesmo leia são pedidos um a um.

inteiro idade
escreva("Qual a sua idade? ")
leia(idade)
escreva("Em dez anos você terá ", idade + 10, " anos\n")

O tempo que o programa passa esperando você digitar não conta no tempo de execução mostrado na barra de status.

Erros

Antes de executar, a IDE verifica o programa inteiro: variáveis não declaradas, tipos incompatíveis, funções chamadas com parâmetros errados, blocos não fechados. O erro aparece no console com linha e coluna, a linha fica marcada no editor e a mensagem tenta dizer como corrigir:

Linha 7, coluna 9: A condição do "se" usa "=" (atribuição). Para comparar valores use "=="

Erros em tempo de execução (divisão por zero, índice fora do vetor, variável usada antes de receber valor, recursão sem fim) também apontam a linha e deixam o painel de variáveis com os valores do momento do erro.

Depurar

  1. Clique na margem esquerda, ao lado do número da linha, para colocar um ponto de parada (bolinha vermelha). Clique de novo para tirar.
  2. Pressione F6 (Depurar). O programa roda até o primeiro ponto de parada. Sem nenhum ponto, pausa na primeira linha.
  3. Avance com F10 Passo (executa a linha sem entrar em funções), F11 Entrar (entra na função chamada), Shift+F11 Sair (volta para quem chamou) e F8 Continuar (até o próximo ponto). Pausar interrompe um programa que está rodando.

O painel Variáveis mostra a pilha de chamadas, do quadro atual para o mais externo, e o valor e o tipo de cada variável; os que mudaram desde a última pausa ficam destacados. Clique em "linha N" para ir até a linha. Estruturas e objetos aparecem com seus campos (Ponto{x: 1.0, y: 2.0}), referências com o valor apontado. Depois de uma execução normal, sem depurar, o painel continua mostrando os valores finais.

Testar

Um teste é um bloco teste "nome" { ... } com afirmações. Pode ficar no próprio programa ou num arquivo separado que o importa (o arquivo de testes enxerga até as funções privadas do programa). Testes não rodam com F5; só com F7 ou pelo painel Testes.

teste "soma de dois números"
{
    afirme_igual(5, soma(2, 3))            // esperado, obtido
    afirme(eh_par(10), "10 é par")         // condição, mensagem opcional
}
teste "programa completo"
{
    entrada("2\n3")                        // o que o usuário digitaria
    inicio()                               // roda o programa
    afirme_igual("Soma: 5\n", saida())     // tudo o que ele escreveu
}

No painel, ▶ ao lado de Todos, de um arquivo ou de um teste executa só aquilo. Cada teste mostra passou/falhou, o tempo e, se falhou, a mensagem com link para a linha. A seção Cobertura traz o percentual de linhas executadas por arquivo, lista as funções que nenhum teste chamou e marca no editor, em verde e vermelho, as linhas cobertas e descobertas. Veja a sintaxe completa das afirmações.

Projetos com vários arquivos

Clique em Pasta (Ctrl+Shift+O) ou arraste uma pasta para a janela. A árvore à esquerda lista os arquivos .koi e as subpastas; o menu de contexto cria, renomeia, exclui (para a lixeira), define o arquivo principal e abre no Explorer. Arquivos editados fora da IDE são recarregados ao voltar para a janela.

Com uma pasta aberta, F5 executa o projeto inteiro: todos os arquivos participam, e o ponto de partida é o arquivo principal. A regra é: o arquivo fixado na barra de status (clique em ▶ para escolher) → a aba ativa, se tiver funcao inicio() → um arquivo chamado principal.koi ou main.koi → o último executado → o único com inicio. Erros e pausas do depurador abrem a aba do arquivo certo.

Um arquivo sem inicio() é um módulo: outros arquivos o usam com importe Nome e enxergam o que ele declarou publico. O exemplo Projeto com vários arquivos abre três abas que funcionam juntas mesmo sem salvar. A sintaxe está em A linguagem → Módulos.

Exemplos e referência

Exemplos abre uma lista de programas prontos, do olá-mundo a classes e testes; cada um abre numa aba nova, já no idioma selecionado. Referência (F1) abre o painel lateral com todas as palavras reservadas, comandos, operadores e funções, com explicação, forma de uso e exemplo que pode ser inserido no editor com um clique. Com o cursor sobre uma palavra, F1 já abre a entrada certa. A mesma referência está nesta documentação: Referência.

Idiomas

O seletor na barra de ferramentas troca o idioma da interface e das palavras reservadas: destaque, autocompletar, referência e exemplos passam para o idioma escolhido. Se houver arquivos abertos, a IDE pergunta se deve converter as palavras reservadas deles; só palavras reservadas e funções nativas mudam, textos entre aspas, comentários e nomes de variáveis ficam como estão, e a conversão de volta é exata. Em qualquer idioma as palavras em português continuam sendo aceitas. A lista completa está em Idiomas.

Perguntas frequentes

O Windows diz que o aplicativo é de um "editor desconhecido".

O instalador ainda não tem assinatura digital. Clique em Mais informações → Executar assim mesmo. O código é aberto e o instalador é gerado automaticamente a partir dele pelo GitHub Actions, com o registro público de cada build.

Funciona em Linux ou macOS?

Sim. Há AppImage e .deb para Linux e um .dmg universal para macOS, todos na mesma release; veja Instalar. A IDE é a mesma nos três sistemas.

Posso usar no navegador?

Não há uma versão hospedada, mas quem baixa o código-fonte pode rodar npm run dev e usar a IDE no navegador, sem o painel de projeto.

Onde fica o rascunho?

Nas preferências da IDE, no seu perfil do Windows. Salve o arquivo (Ctrl+S) para tê-lo numa pasta de verdade e poder enviar para alguém.

Como reporto um problema ou sugiro algo?

Pelas issues no GitHub, com o programa que reproduz o problema. Ideias e dúvidas vão nas discussões.
