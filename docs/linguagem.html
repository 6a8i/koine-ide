A linguagem Koiné

Um tour do básico ao avançado. Koiné é um pseudocódigo com sintaxe de chaves, tipos declarados e mensagens de erro pensadas para quem está aprendendo. Tudo aqui está em português; na IDE, o mesmo código existe em dez idiomas. Cada palavra tem uma entrada detalhada na referência.

Estrutura de um programa

Todo o código fica dentro de programa { }. A função inicio() é por onde a execução começa; as outras funções, variáveis globais e inclusões de biblioteca ficam no mesmo bloco, em qualquer ordem. Comentários usam // até o fim da linha ou /* ... */.

programa
{
    // variável global: visível em todas as funções
    inteiro contador = 0

    funcao inicio()
    {
        escreva("Olá!\n")
        contador++
        cumprimenta("Ana")
    }

    funcao cumprimenta(cadeia nome)
    {
        escreva("Bem-vinda, ", nome, "\n")
    }
}

Comandos são separados por quebra de linha; o ponto e vírgula é opcional e serve para pôr dois comandos na mesma linha.

A verificação de tipos acontece antes de executar. Um inteiro não recebe um real sem conversão explícita (Tipos.real_para_inteiro), mas um real aceita um inteiro. Usar uma variável antes de ela receber valor é erro de execução com mensagem clara.

A precedência é a usual (* antes de +, comparações antes de e, e antes de ou); parênteses resolvem qualquer dúvida.

Entrada e saída

escreva("Nome e idade: ")      // escreve sem pular linha; vários valores separados por vírgula
cadeia nome
inteiro idade
leia(nome, idade)              // lê um valor por vez, do console
escreva("Olá, ", nome, "! Ano que vem: ", idade + 1, "\n")
limpa()                        // limpa o console

leia converte o que foi digitado para o tipo da variável e avisa se não for um número válido. Valores reais aceitam vírgula ou ponto.

Controle de fluxo

Decisão: se / senao

se (nota >= 7.0)
{
    escreva("Aprovado\n")
}
senao se (nota >= 5.0)
{
    escreva("Recuperação\n")
}
senao
{
    escreva("Reprovado\n")
}

Repetição: enquanto, faca ... enquanto, para

inteiro i = 0
enquanto (i < 3)           // testa antes
{
    escreva(i, " ")
    i++
}

faca                       // executa ao menos uma vez
{
    leia(opcao)
} enquanto (opcao < 1 ou opcao > 3)

para (inteiro j = 1; j <= 10; j++)   // início; condição; passo
{
    se (j % 2 == 0) { pare }         // pare sai do laço
    escreva(j, "\n")
}

Escolha múltipla: escolha

escolha (opcao)
{
    caso 1:
        escreva("um\n")
        pare
    caso 2:
    caso 3:                     // sem pare, a execução continua no próximo caso
        escreva("dois ou três\n")
        pare
    caso contrario:
        escreva("outro\n")
}

escolha aceita inteiros, caracteres e cadeias.

Funções

funcao inteiro fatorial(inteiro n)          // tipo de retorno antes do nome
{
    se (n <= 1) { retorne 1 }
    retorne n * fatorial(n - 1)             // recursão
}

funcao trocar(inteiro &x, inteiro &y)      // sem tipo = não retorna nada
{                                           // & passa por referência: altera a variável original
    inteiro t = x
    x = y
    y = t
}

funcao real media(real valores[])           // vetores são sempre passados por referência
{
    real soma = 0.0
    para (inteiro i = 0; i < Util.numero_elementos(valores); i++) { soma += valores[i] }
    retorne soma / Util.numero_elementos(valores)
}

Funções podem ser declaradas depois de serem usadas. Uma função com tipo precisa terminar com retorne em todos os caminhos; o verificador avisa quando falta.

Vetores e matrizes

inteiro notas[5]                      // 5 posições, de 0 a 4, zeradas
inteiro primos[] = {2, 3, 5, 7}       // tamanho pelo conteúdo
real m[3][3]                          // matriz 3×3
inteiro tab[][] = {{1, 2}, {3, 4}}

notas[0] = 10
m[1][2] = 0.5
escreva(primos[3], " ", Util.numero_elementos(primos), " ", Util.numero_linhas(tab), "\n")

Índices começam em 0. Acessar fora do tamanho é erro de execução com a linha e o índice. Vetores podem ter estruturas e objetos como elementos.

Estruturas

Uma estrutura agrupa campos. É um valor: atribuir ou passar para uma função copia; == compara campo a campo.

estrutura Ponto { real x  real y }

funcao inicio()
{
    Ponto a = Ponto(1.0, 2.0)      // construção posicional
    Ponto origem                   // sem valor: campos zerados (Ponto() também)
    Ponto b = a                    // cópia
    b.x = 9.0                      // a.x continua 1.0
    escreva(a, " ", a == Ponto(1.0, 2.0), "\n")   // Ponto{x: 1.0, y: 2.0} verdadeiro
}

funcao real distancia(Ponto p, Ponto q) { retorne Matematica.raiz((p.x - q.x) * (p.x - q.x) + (p.y - q.y) * (p.y - q.y), 2.0) }

Classes e herança

Uma classe tem campos, construtor (função com o nome da classe) e métodos. Objetos são compartilhados: duas variáveis podem apontar para o mesmo objeto, e nulo é um valor válido. Campos e métodos são privado por padrão (visíveis na classe e nas subclasses); publico abre para fora.

classe Forma
{
    privado cadeia nome
    publico Forma(cadeia nome) { este.nome = nome }
    publico real area() { retorne 0.0 }
    publico cadeia descreve() { retorne nome + " com área " + area() }   // chama a versão da subclasse
}

classe Circulo herda Forma
{
    privado real raio
    publico Circulo(real r)
    {
        super("círculo")       // construtor do pai, sempre o primeiro comando
        raio = r
    }
    publico real area() { retorne Matematica.PI * raio * raio }   // sobrescreve
}

funcao inicio()
{
    Forma f = Circulo(2.0)                 // polimorfismo: f.area() chama Circulo.area
    escreva(f.descreve(), "\n")
    Forma g = nulo
    se (g == nulo) { escreva("sem forma\n") }
}

Uma subclasse não pode ser atribuída a partir da classe-mãe sem conversão (o verificador explica: "nem todo Forma é Circulo"). Chamar um método em nulo é erro de execução apontando a linha.

Referências

Uma ref aponta para uma variável, um elemento de vetor ou um campo. É segura: não existe aritmética, só pegar o endereço com & e acessar com *.

inteiro n = 10
ref inteiro r = &n
*r = 20                        // n agora é 20
incrementa(&n)                 // ou passe a referência para uma função
escreva(n, " ", r == nulo, "\n")   // 21 falso

funcao incrementa(ref inteiro x) { *x = *x + 1 }

Comparar duas referências diretamente é erro (compare *a == *b), assim como fazer contas com a referência em vez do valor.

Módulos

Um arquivo sem inicio() é um módulo. Outro arquivo da mesma pasta o importa com importe e usa tudo o que ele declarou publico: funções, variáveis, constantes, estruturas e classes. O que não é público fica privado ao módulo.

geometria.koi
programa
{
    modulo Geometria            // opcional; o padrão é o nome do arquivo
    publico const real PI = 3.14159
    publico estrutura Ponto { real x  real y }

    publico real distancia(Ponto a, Ponto b)
    {
        retorne raiz(quadrado(a.x - b.x) + quadrado(a.y - b.y))
    }
    real quadrado(real v) { retorne v * v }      // privada ao módulo
    real raiz(real v) { retorne Matematica.raiz(v, 2.0) }
    inclua biblioteca Matematica
}
principal.koi
programa
{
    importe Geometria
    // ou: importe "lib/geometria.koi" --> geo

    funcao inicio()
    {
        Ponto a = Ponto(0.0, 0.0)
        Ponto b = Ponto(3.0, 4.0)
        escreva(Geometria.distancia(a, b), "\n")   // 5.0
        escreva(distancia(a, b), "\n")             // sem qualificar também vale, se não houver ambiguidade
    }
}

Importações circulares, módulos repetidos e nomes ambíguos (duas importações com a mesma função) são erros apontados no arquivo certo. Na IDE, F5 executa o projeto inteiro; veja Projetos.

Testes

Um teste é um bloco com nome que roda isolado (as globais são reiniciadas a cada teste) e falha quando uma afirmação não se cumpre. Pode ficar no próprio programa ou num arquivo separado que importa o programa, e nesse caso enxerga até as funções privadas.

programa
{
    importe calculadora

    teste "soma de dois números"
    {
        afirme_igual(5, soma(2, 3))                   // esperado, obtido
        afirme_diferente(0, soma(2, 3))
        afirme(eh_par(10), "10 é par")                // condição, mensagem opcional
        afirme_aproximado(2.5, media(2, 3), 0.001)    // reais, com tolerância
    }

    teste "programa completo, com entrada e saída"
    {
        entrada("2\n3")                // o que o usuário digitaria
        inicio()                       // executa o programa
        afirme_igual("Soma: 5\n", saida())
    }
}
AfirmaçãoFalha quando
afirme(cond[, msg])a condição é falsa
afirme_igual(esperado, obtido[, msg])os valores diferem (estruturas campo a campo, vetores item a item, objetos por identidade)
afirme_diferente(a, b[, msg])os valores são iguais
afirme_aproximado(esperado, obtido, tolerancia[, msg])a diferença passa da tolerância
entrada(texto) / saida()fornecem as próximas linhas para leia e devolvem tudo o que o programa escreveu

Os testes rodam com F7 ou pelo painel Testes, que também mostra a cobertura. Veja Testar no guia.
